# Bundled Noto Sans

Unmodified hinted TrueType Regular and Bold from notofonts/noto-fonts:
https://github.com/notofonts/noto-fonts/tree/main/hinted/ttf/NotoSans
Downloaded 2026-09-20. SIL Open Font License is included in OFL.txt.
Both fonts contain Latin Extended, Greek and Cyrillic glyphs. Unit tests inspect
representative script/diacritic coverage; QA images were also visually inspected.
